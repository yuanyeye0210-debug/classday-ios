# classday-ios

课间 / Classday is a native SwiftUI iPhone timetable with a WidgetKit extension. The project lives in [`Classday/`](Classday/).

This repository does not ship an App Store build. Sideload installs use SideStore and LocalDevVPN. The source, which lists the current and previous IPAs, is `https://raw.githubusercontent.com/yuanyeye0210-debug/classday-releases/main/apps.json`. See [Classday/Docs/SIGNING.md](Classday/Docs/SIGNING.md).
