# Classday iOS 2.8.0 真机回归清单

> 手动核对清单：以下每一项都在真机上人工操作、人工核对。不是自动化脚本，本机（Linux，无 Swift/Xcode、无真机）无法运行其中的任何一项；逐项打勾前请先在真机上完成对应操作。

## 1. 启动（2.3.4–2.3.6 启动闪退回归，2.3.7 已修）

- [ ] 真机冷启动 App（从后台划掉后重新打开），期望：正常进入主界面，不闪退、不卡在启动屏。
- [ ] 冷启动后进入“设置 → 外观/动效”页并上下滑动，期望：页面正常显示、无卡死、无启动即闪退（对应 MotionTracker.sensitivity 不再自赋值）。
- [ ] 切换一次主题后退回主界面，期望：界面正常刷新，无闪退、无白屏。

## 2. App Group 读写

- [ ] 在主 App 里改一节课的时间并保存，期望：小组件随后刷新后显示改后的时间（App Group 共享数据已同步）。
- [ ] 在主 App 里新增一门课并保存，期望：小组件随后刷新后出现这门课。
- [ ] 杀掉主 App 后只看小组件，期望：小组件仍能显示课表（读的是 App Group 共享数据，不是主 App 内存）。

## 3. 小组件

- [ ] 看“下一节”小组件，期望：显示离现在最近的下一节课及其开始时间，与主 App 一致。
- [ ] 看“今日课程”小组件，期望：列出今天全部课程，顺序与时间与主 App 一致。
- [ ] 看小组件时间线，期望：覆盖未来 7 天的课程时间线，无缺课、无重复、无错乱时间。

## 4. 本地提醒

- [ ] 打开一门课的上课提醒，期望：系统只在开了提醒时才弹出通知权限申请；未开提醒的课不申请权限。
- [ ] 把全部课程的提醒都打开，期望：待发送的本地提醒总数不超过 60 条。
- [ ] 到一节课的提醒时间，期望：准时收到一条本地提醒，内容是该节课而非别的课。

## 5. 周视图拖动

- [ ] 在周视图把一节课拖到与另一节课冲突的时间，期望：拖动被取消，课程回到原位置，不产生重叠。
- [ ] 在周视图把一节课拖到空闲时间，期望：课程落到新时间；随后撤销，期望：课程回到拖动前的位置。

## 6. AI 草稿确认（成绩、假期、停课三条路）

- [ ] 用 AI 识别一张成绩截图，期望：只生成草稿，不直接写入成绩；点“确认”后才写入，点“取消/放弃”则不写入。
- [ ] 用 AI 识别一张校历图片，期望：只生成假期草稿，不直接写入日程；点“确认”后才写入，点“取消/放弃”则不写入。
- [ ] 用 AI 识别一条停课通知，期望：只生成停课草稿，不直接取消课程；点“确认”后才取消对应课程，点“取消/放弃”则课程不变。

## 7. 检查更新

- [ ] 当前已是最新版时点“检查更新”，期望：明确写明“已是最新版”，不跳转、不报错、不提示有并不存在的更新。
- [ ] 有新版时点“检查更新”（如有可用的新版可测），期望：提示新版本号并给出更新入口；若无新版可测则跳过此项。

## 8. 降级（低电量 / 减弱动态效果）

- [ ] 打开系统低电量模式后回到 App，期望：实际生效省电档（设置页提示已降档），着色器、陀螺仪、粒子全关。
- [ ] 打开系统“减弱动态效果”后回到 App，期望：实际生效省电档，着色器、陀螺仪、粒子全关。
- [ ] 同时关闭低电量模式与“减弱动态效果”并选回高性能档，期望：着色器、陀螺仪、粒子恢复正常工作。

## 9. 同名课程合并

- [ ] 同名课合并后成绩/GPA/提醒正常。

## 10. 设置页分组导航（2.9.1，设置 → 六个子页）

- [ ] 在“我的”页依次点进上课时间、学期、假期与不上课时段、提醒、数据、关于六个子页再返回，期望：每个子页都能进出，首页顶部主题/考试卡片与“课表”“通用”两张卡片六行都在，子页内容完整、无控件缺失。
- [ ] 在上课时间子页改一节的起止时间后点“保存节次与学期”，返回再进，期望：改动已保存，值还在。
- [ ] 在学期子页改学期名称后不点保存直接返回，再进学期子页，期望：未保存的修改还在（草稿不丢）；点“保存学期”后再返回、再进，期望：改动已保存。
- [ ] 在假期与不上课时段子页新增一段假期，期望：立即保存，返回再进仍在；删一段假期，期望：立即删除。
- [ ] 在假期与不上课时段子页点“校历导入”与“邮件停课识别”，期望：两个 sheet 都能打开，草稿确认后正确写入假期/停课记录。
- [ ] 在提醒子页改默认提前分钟后点“保存提醒”，返回再进，期望：改动已保存；改完不点保存直接返回、再进，期望：草稿不丢。
- [ ] 在数据子页点“导出数据”，期望：能正常导出文件；点“导入数据”选一份课表 JSON，期望：导入成功；点“清空课程”并确认，期望：课程被清空（谨慎操作，先备份）。
- [ ] 在数据子页点“导入数据”，选择 JSON/ICS/图片/文件或粘贴文字；核对摘要或课程草稿，取消不写入，确认才替换备份或追加识别结果；没有恢复演示数据入口。
- [ ] 在关于子页点“检查更新”，期望：已是最新版时明确提示；有新版时提示版本号并能按 SideStore 安装步骤完成下载安装。

## 11. Live Activity 后台刷新（周末/长假断档修复）

> 本节只覆盖本分支改动：horizon 7 天 + 午夜心跳、课前 60 分钟唤醒、长课日重建、过期态显示、小组件时间线 7 天、关于页后台刷新提示。本地通知兜底（方案 D）本次未做，无需点验通知。

- [ ] 周末断档：周五最后一节课后不再打开 App，周一早上第一节课前看锁屏，期望：Live Activity 已出现，内容是周一第一节课（课名/时间/地点正确），不是周五的课，也不是空白。
- [ ] 周末断档（低电量模式）：开低电量模式过一个周末，周一早上看锁屏，期望：Live Activity 仍在第一节课前出现、内容正确（后台刷新是 best-effort，低电量下系统可能推迟；若系统推迟未出现，打开 App 后立即恢复即算通过）。
- [ ] 长假断档：放一个 3 天以上无课的长假（如国庆），假期中不打开 App，假期后第一个有课日早上看锁屏，期望：Live Activity 在第一节课前出现、内容正确。
- [ ] 过期态显示（锁屏卡片）：让一节课结束且 Activity 过期，期望：锁屏卡片不再显示往上数的计时器，改显示“已结束，打开课曜查看下一节”。
- [ ] 过期态显示（灵动岛展开态）：同上，展开灵动岛，期望：展开态同样显示“已结束，打开课曜查看下一节”，不显示往上数的计时器。
- [ ] 过期态显示（灵动岛 compact）：同上，看灵动岛 compact/minimal，期望：只剩图标，无往上数的计时器。
- [ ] 后台刷新被关的提示：系统设置里关掉课曜的“后台 App 刷新”，再进 App“设置 → 关于”，期望：出现“后台刷新已关，锁屏下一节只在打开 App 后更新。”的提示；重新打开后台刷新后进关于页，期望：该提示消失。
- [ ] 强退后的行为：强退 App（从后台划掉）后过一个周末，周一早上看锁屏，期望：Live Activity 不出现（链断是预期行为）；重新打开 App，期望：前台重种生效，Live Activity 立即出现、内容正确。
- [ ] 长课日重建：排一个 08:00–21:00 的课日（第一节 08:00 开始、最后一节 21:00 结束），当天不手动打开 App，下午 15:00 后看锁屏/灵动岛，期望：Activity 不断（已存活约 7 小时且后面还有课时应 end 后重建，重开 8 小时窗口），晚课仍正常显示。
- [ ] 课前唤醒：周一第一节课 08:00 开始，周一 07:00 前后看锁屏，期望：Activity 在 07:00 唤醒后出现（第一节课前 60 分钟），内容是第一节课；若 07:00 的任务被系统推迟，期望：Activity 出现晚但内容正确（第一节课进行中），且锁屏小组件在此期间仍显示正确的下一节。
