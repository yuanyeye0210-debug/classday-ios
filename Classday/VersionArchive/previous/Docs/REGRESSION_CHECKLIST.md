# Classday iOS 2.8.0 真机回归清单

> 手动核对清单：以下每一项都在真机上人工操作、人工核对。不是自动化脚本，本机（Linux，无 Swift/Xcode、无真机）无法运行其中的任何一项；逐项打勾前请先在真机上完成对应操作。

## 1. 启动（2.3.4–2.3.6 启动闪退回归，2.3.7 已修）

- [ ] 真机冷启动 App（从后台划掉后重新打开），期望：正常进入主界面，不闪退、不卡在启动屏。
- [ ] 冷启动后进入“设置 → 外观/动效”页并上下滑动，期望：页面正常显示、无卡死、无启动即闪退（对应 MotionTracker.sensitivity 不再自赋值）。
- [ ] 切换一次主题后退回主界面，期望：界面正常刷新，无闪退、无白屏。

## 2. App Group 读写

- [ ] 在主 App 里改一节课的时间并保存，期望：小组件随后刷新后显示改后的时间（App Group 共享数据已同步）。
- [ ] 在主 App 里新增一门课并保存，期望：小组件随后刷新后出现这门课。
- [ ] 杀掉主 App 后只看小组件，期望：小组件仍能显示课表（读的是 App Group 共享数据，不是主 App 内存）。

## 3. 小组件

- [ ] 看“下一节”小组件，期望：显示离现在最近的下一节课及其开始时间，与主 App 一致。
- [ ] 看“今日课程”小组件，期望：列出今天全部课程，顺序与时间与主 App 一致。
- [ ] 看“36 小时时间线”小组件，期望：覆盖今明两天的课程时间线，无缺课、无重复、无错乱时间。

## 4. 本地提醒

- [ ] 打开一门课的上课提醒，期望：系统只在开了提醒时才弹出通知权限申请；未开提醒的课不申请权限。
- [ ] 把全部课程的提醒都打开，期望：待发送的本地提醒总数不超过 60 条。
- [ ] 到一节课的提醒时间，期望：准时收到一条本地提醒，内容是该节课而非别的课。

## 5. 周视图拖动

- [ ] 在周视图把一节课拖到与另一节课冲突的时间，期望：拖动被取消，课程回到原位置，不产生重叠。
- [ ] 在周视图把一节课拖到空闲时间，期望：课程落到新时间；随后撤销，期望：课程回到拖动前的位置。

## 6. AI 草稿确认（成绩、假期、停课三条路）

- [ ] 用 AI 识别一张成绩截图，期望：只生成草稿，不直接写入成绩；点“确认”后才写入，点“取消/放弃”则不写入。
- [ ] 用 AI 识别一张校历图片，期望：只生成假期草稿，不直接写入日程；点“确认”后才写入，点“取消/放弃”则不写入。
- [ ] 用 AI 识别一条停课通知，期望：只生成停课草稿，不直接取消课程；点“确认”后才取消对应课程，点“取消/放弃”则课程不变。

## 7. 检查更新

- [ ] 当前已是最新版时点“检查更新”，期望：明确写明“已是最新版”，不跳转、不报错、不提示有并不存在的更新。
- [ ] 有新版时点“检查更新”（如有可用的新版可测），期望：提示新版本号并给出更新入口；若无新版可测则跳过此项。

## 8. 降级（低电量 / 减弱动态效果）

- [ ] 打开系统低电量模式后回到 App，期望：实际生效省电档（设置页提示已降档），着色器、陀螺仪、粒子全关。
- [ ] 打开系统“减弱动态效果”后回到 App，期望：实际生效省电档，着色器、陀螺仪、粒子全关。
- [ ] 同时关闭低电量模式与“减弱动态效果”并选回高性能档，期望：着色器、陀螺仪、粒子恢复正常工作。
