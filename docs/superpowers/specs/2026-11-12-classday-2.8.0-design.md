# Classday 2.8.0 底子与稳定 — 设计

批准：Eric，2026-11-12，做法 A（Core 先行）。

## 意图和为什么

第一批 2.8.0 只做底子，不做新功能。README 还停在 V1 / 1.0.0，实际已经 2.7.1；版本号三个来源已经散了；三个 AI 入口各自为政；2.3.7 出过真机启动栈溢出。先把这三件事收正，后面的改动和安卓同步才不会越改越散。

## 目标

- P0-1 文档、版本和 schema 对齐：README、版本号、schema v1 对齐；版本号只留一个来源；核实 VERSION 文件位置；README 补到 2.7.1 的功能（成绩、假期、停课 AI）；冻结 schema v1 的字段语义。
- P0-2 AI 统一管道放进 ClassdayCore：一个中间 JSON（置信度、来源、原始文本），识别 → 草稿 → 确认 → 写入 Store；成绩、假期、停课三个解析器共用这套；Gemini 密钥只存钥匙串，不进仓库；纯逻辑，能在 Linux 跑测试。
- P0-3 真机回归清单和视觉、震动降级开关：只加配置开关，不改界面；默认稳态，出问题一键关；清单覆盖启动、App Group、小组件、提醒、拖动、AI 草稿确认。

## 非目标

不改 UI 设计，不加新 AI 功能，不升 schema v2，不写安卓代码，不改 SideStore 分发。

## 反目标

不破坏 2.7.1 现有行为；不把中文写进 Core 数据模型；不把密钥写进仓库；不只改 iOS，不留安卓能用的版本。

## 约束

- 本机是 Linux，没有 Swift、Xcode、模拟器和真机。Core 测试用 `swift test`，只能走 GitHub Actions（macos-latest，见 `.github/workflows/classday-ios-ipa.yml`）或 Eric 的 Mac 验证；界面和真机验证靠 Eric。
- GitHub 代码搜索对这个仓库不全，以本地 clone 为准。
- 安卓版在 GitHub 上没找到（2026-11-12 已查：8 个仓库里 `android` / `kotlin` / `apk` 都是 0 结果，releases 只有 `.ipa`）。本批只保证共享逻辑、数据结构和行为跨平台可用，不写安卓代码。
- 分发不变：侧载，LocalDevPN + SideStore，安装包在 classday-releases。

## 已查到的事实（实施起点）

- 版本号三个来源已散：`Classday/VERSION` 文件在 HEAD 里不存在（只在 `Classday/VersionArchive/previous/VERSION` 里有一份 1.0.1）；`Classday/project.yml` 的 MARKETING_VERSION 是 `2.0.0`；`Classday/Classday.xcodeproj/project.pbxproj` 是 `2.7.1`（4 处）。`Classday/Tools/bump-version.sh` 要求 HEAD 有 `Classday/VERSION`，现在会直接退出；`Classday/Tools/check_project.py` 和 `check_version_snapshot.py` 也都读 `Classday/VERSION`，现在跑不通。
- 三个 AI 解析器都在 `Classday/ClassdayCore/Sources/ClassdayCore/ScheduleExtras.swift` 里：`ICSImporter`（约 294 行）、`HolidayImporter`（约 1948 行，`parseICS` / `parseAI`）、`GradeSchemeParser`（约 1898 行）、`CancellationParser`（约 2075 行）与 `CancellationDraft`（约 2057 行）；`ClassCancellation` 在 `Models.swift:351`。UI 侧的草稿确认在 `CourseDetailView.swift`（记分规则识别）和 `SettingsView.swift`（假期、停课）里，Gemini 密钥入口也在那两处。
- 视觉、震动相关代码在 `Classday/ClassdayApp/Sources/Theme.swift`、`Experience.swift`（含 MotionTracker）以及 `Classday/ClassdayShaders.metal`；2.3.7 的栈溢出是 `MotionTracker.sensitivity` 的 `didSet` 自赋值。
- 测试在 `Classday/ClassdayCore/Tests/ClassdayCoreTests/`，共 8 个文件，包括 `V2FeatureTests.swift`（假期、ICS、成绩相关单测已在）。

## 做法

选 A，Core 先行。B 不做：界面一起改、必须真机验证，现在改动太大。C 不做：留适配器临时代码，下一版还得再迁。
