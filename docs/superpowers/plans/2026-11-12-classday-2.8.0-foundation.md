# Classday 2.8.0 底子与稳定 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 2.8.0 第一批（P0-1 文档版本对齐、P0-2 AI 统一管道、P0-3 回归与降级开关），只动 Core 与配置，不改 UI 设计，不加新功能。

**Architecture:** Core 先行。共享逻辑进 `ClassdayCore`（Swift Package，Linux 可测）；App 层只做接线（一个 Gemini 客户端、三个草稿确认入口复用 Core 的统一结果类型）；版本号以恢复的 `Classday/VERSION` 为单一来源。

**Tech Stack:** Swift 5.9（ClassdayCore，swift-tools 5.9，iOS 17 / macOS 13，无外部依赖）、Python 3（`Classday/Tools/` 静态检查）、GitHub Actions（macos-latest，见 `.github/workflows/classday-ios-ipa.yml`）。

**Spec:** `docs/superpowers/specs/2026-11-12-classday-2.8.0-design.md`

## Global Constraints

- 当前版是 `2.7.1`（`Classday/Classday.xcodeproj/project.pbxproj` 里 4 处 `MARKETING_VERSION = 2.7.1;`）。恢复后的 `Classday/VERSION` 必须是 `2.7.1`，`Classday/project.yml` 的 `MARKETING_VERSION` 必须是 `"2.7.1"`（现在是 `"2.0.0"`）。
- 数据 schema 是 v1，冻结：不升 v2，不改现有字段语义；新增字段只能是可选且带 `decodeIfPresent` 兼容。
- Gemini 模型固定为 `gemini-3.1-flash-lite`；密钥只存钥匙串，service `com.classday.app`，account `gemini-grade-key`，绝不进仓库、不进日志、不出现在测试固件里。
- 中文不写进 Core 数据模型；Core 里的枚举值、字段名用英文稳定值（如 `blue`、`all`、`am`、`pm`、`day`）。
- 安卓版在 GitHub 上没找到，本批不写安卓代码；但共享逻辑、数据结构、行为必须跨平台可用。
- 分发不变：侧载，LocalDevPN + SideStore，安装包在 classday-releases；不改分发和更新流程。
- 不 push、不建 PR、不合并；分支留在本地 worktree。
- 本机是 Linux，没有 Swift、Xcode、真机，`swift` 命令不存在：本地不跑 `swift test` / `xcodebuild`；本地验证用 `python3 Classday/Tools/check_project.py` 和 `python3 Classday/Tools/check_version_snapshot.py --self-test`；Swift 编译与测试走 GitHub Actions 或 Eric 的 Mac，在报告里分开写。
- 提交信息沿用仓库风格：`2.8.0 <P0-x>：<一句话中文描述>`，例如 `2.8.0 P0-1：恢复 VERSION 与版本对齐`。

- 版本恢复：base（main）里没有 `Classday/VERSION`，恢复它的提交不能被快照检查器当成“没归档就改版”拦下，也绝不能伪造一份 previous 快照。测试：Task 1 的恢复例外自测用例。

```swift
public enum AIRecognitionSource: String, Codable, Equatable, Hashable, Sendable {
    case grade
    case holiday
    case cancellation
}

public enum AIRecognitionPayload: Codable, Equatable, Sendable {
    case grade(GradeScheme)
    case holidays([HolidayPeriod])
    case cancellation(CancellationDraft)
}

public struct AIRecognitionResult: Codable, Equatable, Sendable {
    public var source: AIRecognitionSource
    public var confidence: Double?
    public var rawText: String
    public var payload: AIRecognitionPayload
}

public enum AIRecognition {
    public static func parse(_ text: String, source: AIRecognitionSource, courses: [Course] = [], calendar: Calendar = ClassdayCalendar.make()) -> AIRecognitionResult?
}
```
