# 功能 8：两端今日首页复核材料

状态：待平台编译、设备交互与真实截图审美复核。没有以静态检查或核心单测代替界面验收。

## 本轮页面结构

- iOS：沿用今日页，优先显示当前/下一节课程与今天课程。日程、考试倒计时和作业进入默认收起的“日程、考试与作业”，原有操作保留。
- Android：默认进入今日，新页只放当前/下一节课程和今天课程。底部保留课表、倒计时、我的，加今日一项；周课表及长按调课仍在课表页。打开下一节课快捷入口转到今日。
- 两端课表读取失败时显示恢复提示，不在今日展示回退演示课程。正常演示模式保留明确“演示数据”说明。
- Android 每 30 秒更新当前时刻；今日课程由设备日历日期生成，不跟随周课表翻周。跨日下一节带日期；iOS 复用下一节卡片的日期/倒计时说明。

5. 两端读盘失败提示，恢复成功后今日重新显示真实课表，正常演示模式与异常回退不能混淆。
