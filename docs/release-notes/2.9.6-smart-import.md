# 2.9.6 智能导入修复说明

智能导入现在会按当前学期设置的上下课时间匹配节次，避免自定义作息下导入后的课程时间发生偏移。直接填写节次的导入方式保持不变。

源文件同时写了节次和上课/下课时间时，以节次为准，时间只用来核对：节次有效但与时间对不上，会提示核对节次设置，不会悄悄按时间改节次。若写的节次在本学期不存在、但开始和结束时间完整，会按时间导入，并在提示里说明将按下方时间导入（Android 的预览还会写明替换成了哪几节）；时间不完整则跳过或阻止导入。只写了开始时间、没写结束时间的行，也按已写的节次导入，不再整行丢掉。粘贴的纯文字、拍照或相册识别出的文本行同样如此：写了「第3-4节」或「第3节」就按节次导入，不会再默认落到第一节；同时写了时间则以节次为准、时间只用来核对。

- Android：无法准确匹配当前学期作息（且没有完整时间可核对）、或节次与时间互相矛盾的安排会被跳过，并显示具体原因；源节次本学期不存在但时间完整时按时间导入，预览提示里会写明替换成了哪几节；其余可导入课程仍需预览确认后才写入。
- iOS：节次超出本学期范围、缺少节次或起止倒序但时间完整时，会提示将按时间导入，不需要额外确认；时间不完整会阻止导入并提示补齐。节次与时间互相矛盾时，仍提示核对学期节次设置或修改课程，处理后才能确认导入。

本次修复不会自动修改已导入的课程；此前时间有误的课程仍需自行核对。独立 ICS 文件导入也会按当前学期作息准确匹配，无法对应的课程事件会跳过并提示；考试和作业的处理方式保持不变。
