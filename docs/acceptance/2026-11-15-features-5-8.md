## 取得可运行环境后的执行顺序

1. 在具备 Swift/Xcode 的环境先运行 `Classday/ClassdayCore` 中的 `swift test`，修复失败，再验证 iOS 应用和小组件编译、Siri 元数据及侧载共享快照。当前本地模式下不自动触发云端。
2. 在具备 Android SDK 的环境运行 Debug 单测与应用编译，先看日志修错，再进行设备操作；不以核心脚本成功代替这一步，不为验收读取或改动发布签名密钥。
3. 使用测试课表核对空表/读取失败/恢复、上课开始结束、跨午夜、假期停课和临时调课。功能 7 样例：平时 80、占比 40%、期末 60%，目标总分 60 时最低期末约 46.6667；界面按 0.01 分向上显示 46.67。保留未填分数、负权重和越界旧分数的拒绝测试。
4. 使用测试照片/文件核对导入取消不写入、解析失败不导入半份数据、预览后明确确认才追加。拍照中断后重新进入数据页，验证仅清理超一天且不活动的本流程文件；不能误删相册原图或无关文件。
5. 按现有 UI 复核包补真实截图和操作证据，再决定是否勾选总需求。材料见 [外观页](../ui-review/2026-11-15-settings-appearance.md) 和 [今日首页](../ui-review/2026-11-15-today-home.md)。
